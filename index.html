ML prediction of finite-size convergence

Built a machine-learning pipeline to predict the minimal safe crop length needed for reliable convergence of real-space topological invariants in finite non-Hermitian systems.

  • Generated structured simulation datasets.
  • Engineered scaling features from model parameters.
  • Used regression and classification models to predict convergence behavior.
  • Interpreted ML results through physical scaling laws.
Python scikit-learn Regression Feature engineering

Higher-neighbor Hatano-Nelson models

Extended asymmetric hopping models from nearest-neighbor to higher-neighbor chains to study scaling, finite-size effects, and oscillatory convergence patterns.

  • Designed parameter sweeps across model families.
  • Tracked phase labels, convergence thresholds, and scaling variables.
  • Compared numerical results with analytical expectations.
  • Built reusable analysis code for multiple model classes.
Numerical analysis Scaling Simulation data

Quantum transport in HgTe devices

Developed numerical simulations of multi-terminal H-bar devices to study nonlocal resistance, spin Hall response, and probe-dependent transport signatures.

  • Built simulation workflows using Kwant.
  • Analyzed conductance matrices and transport observables.
  • Created diagnostic plots for current flow and spin-resolved response.
  • Studied how device geometry and contacts affect measured signals.
